# 植物种植指南生成器

把「植物 × 城市 × 位置」三个变量，编译成一份可直接阅读、可分享的单文件 HTML 指南。
设计语言固定为**暖纸质 + 编辑杂志风**，排版与配色由模板固化，内容按城市与位置定制。

## 核心原则

1. **城市与位置是硬输入**。没有它们，气候与微环境无从判断，指南只能沦为空泛的通用教程。缺失时必须先问，不允许用「一般情况」蒙混。
2. **数字优先**。日照时数、极端低温、浇水间隔、肥料浓度——能用数字说清的，不用形容词。
3. **样式不重写**。设计系统已固化在 `assets/guide-template.html`，只替换内容层，不另造 CSS。
4. **每章给判断，不给说明书**。读者带问题而来，要的是「为什么」和「该怎么做」的结论。

## 工作流

### 第 1 步 — 收集参数（必做）

必须拿到以下三项中的关键两项：

| 参数 | 说明 | 缺失时 |
|---|---|---|
| **城市** | 决定气候、耐寒区、日照、极端温度、季节节奏 | **必须询问** |
| **种植位置** | 室内 / 室外 + 具体形态（露台、庭院、南向阳台、封闭阳台、北向窗边等） | **必须询问** |
| 植物 | 具体植物名；未指定则按城市 + 位置推荐适配清单 | 不追问，走推荐分支 |

位置只说到「阳台 / 室外」这种粒度时，继续追问**朝向**与**是否封闭**——
这两项对结论的影响与城市同等重要（南向封闭阳台与北向开放阳台是两种生境）。

用 AskUserQuestion 一次问清，不要分多轮挤牙膏。三个参数都在用户首句话里给全时，跳过此步。

### 第 2 步 — 建立气候与微环境档案

1. 读 `references/climate-zones.md`，定位目标城市档案（年均温、极端低温、耐寒区、年日照时数、湿度特征、气候事件）。
   表中没有的城市或境外城市：**联网核查**同一组变量后再继续，不要外推。
2. 读 `references/microclimate.md`，把位置描述翻译成：日累计直射时长、照度区间、夏峰值温 / 冬谷值温、通风与湿度水平、容器约束。
3. 形成一句话结论，例如：「成都露台 = 全日照但年日照仅 1000～1200h，夏闷热冬湿冷，主要矛盾是夏季蒸腾失控与冬季 0℃ 线」。

### 第 3 步 — 确定植物清单

- **已指定植物**：从 `references/plant-library.md` 核对光照需求、适温、耐寒区、毒性；联网补充该植物的品种差异与最新栽培共识。植物耐寒区高于城市分区两档以上时，在正文明确指出风险，并给出盆栽 + 入室的替代方案。
- **未指定植物**：按第 2 步的照度与温度区间，从库中挑出 5～6 个适配项，按「第一梯队闭眼入 / 第二梯队有条件入 / 避坑清单」组织成六张卡片。
- 涉及有毒植物时，必须在正文中显式标注毒性与防护方式。

### 第 4 步 — 视觉定调 + 生成骨架

按植物特点选**主题色**与**首屏装饰形态**，两者独立选择：

| data-theme | 强调色 / 纸底 | 适配植物 |
|---|---|---|
| `bloom` | 玫红 / 暖纸 | 暖调浓花：三角梅、天竺葵、石榴、矮牵牛、芙蓉、月季红黄系 |
| `leaf` | 叶绿 / 微冷绿纸 | 观叶阴生：龟背竹、蕨类、竹芋、绿萝、橄榄、琴叶榕 |
| `harvest` | 琥珀 / 暖纸 | 果蔬香草与沙生：番茄、无花果、蓝莓、迷迭香、多肉、仙人掌 |
| `orchid` | 紫罗兰 / 冷纸 | 雅致冷调花：兰花、薰衣草、紫薇、紫花重瓣系 |
| `aqua` | 黛蓝 / 冷纸 | 蓝紫系花与喜湿清透：蓝雪花、绣球蓝状态、风信子、勿忘我 |
| `frost` | 冰蓝 / 最冷纸 | 球根白花与耐寒：水仙、雪滴、白郁金香、雪滴花、高山植物 |

规则：以**主力植物的花色/气质**取色，不是以叶色；混合种植时取占比最大或 C 位植物的色系。

首屏装饰形态（`--flora` 参数，按主力植物的**花序/叶形特征**选，与主题色独立）：

| --flora | 形态 | 适配植物特征 |
|---|---|---|
| `petal` | 五瓣花 | 蔷薇科、三角梅、矮牵牛、芙蓉等常规单瓣花 |
| `double` | 重瓣同心圆 | 月季、牡丹、茶花、重瓣矮牵牛等重瓣花 |
| `spike` | 穗状花序 | 薰衣草、鼠尾草、狐尾百合、飞燕草 |
| `umbel` | 球序/伞形 | 绣球、大花葱、百子莲 |
| `composite` | 菊科头状 | 向日葵、雏菊、波斯菊、金光菊 |
| `fern` | 羽叶 | 蕨类、文竹、羽叶薰衣草 |
| `split` | 裂叶/孔叶 | 龟背竹、春羽、橡皮树等观叶默认选它 |
| `succulent` | 莲座 | 多肉、芦荟、仙人掌科 |
| `none` | 无装饰 | 用户明确不要装饰时 |

微调参数：`--flora-size <px>` 宽度、`--flora-rot <度>` 旋转、`--flora-sway` 轻摆动画（穗状/羽叶类摇曳感更好，花朵类可加 8~15 度斜角）。
推荐分支（用户未指定植物）时，按第一梯队里排位最前的植物的形态与色系定调。

```bash
python scripts/new_guide.py --out "<工作目录>/<植物>-<城市>-<位置>-种植指南.html" \
  --theme aqua --flora umbel --title "<植物> · <城市><位置>种植指南"
```

> 脚本使用 Python 3.10+ 语法（如 `int | None` 联合类型），需 **Python 3.10 或更高版本**运行；纯标准库，无第三方依赖。

脚本会打印全部待填占位符清单。

### 第 5 步 — 填写内容

按 `references/content-blueprint.md` 的固定十章结构填写，组件用法直接照抄模板内已有的实例：

| 内容类型 | 用哪个组件 |
|---|---|
| 认知冲击 / 数据对比 | 首屏 `.stat-row` 三个数字 |
| 是与否的对比 | `.compare` 表 + `.yes` / `.no` 类 |
| 分步操作 | `.ruler`（大号序号）或 `.ruler.plain`（纯文本） |
| 并列要点 / 品种卡片 | `.three` 里的 `.vcard` |
| 一句话忠告 | `.tip` |
| 极端季强调 | `.callout`（超大数字 + 短句） |
| 全年节奏 | `.cal` 十二格 + 口诀卡 |
| 疑问解答 | 六个 `<details>`，第一个加 `open` |

写作细节、首屏文案公式与禁用词清单见 `references/content-blueprint.md`。

### 第 6 步 — 质检

- 全文搜索 `{{`，必须为 0 命中。
- 城市 / 位置在首屏、月历、极端季章节中前后一致；月历体现该城市的季节节奏。
- 三个 stat 数字至少两个有真实来源（来自气候档案或联网核查）。
- 无空洞形容词与 AI 味套话（见蓝图里的禁用清单）。
- 375px 宽度下表格用 `.tbl-wrap` 横向滚动，不破版。
- 农药写通用成分名并注明安全间隔；不写商品名。

### 第 7 步 — 交付

用 present_files 展示生成的 HTML。附一段 3～5 行说明：城市与位置的气候结论、
最关键的 1～2 个养护动作、以及指南中的风险提示。

## 模板使用规则

`assets/guide-template.html` 是设计的唯一来源，包含完整的令牌层、全部组件与动效脚本。
生成指南时：

- **保留 `<style>` 块不动**。需要换强调色只改 `<html data-theme="...">`，不要改 CSS 变量。
- **保留 `<script>` 块不动**。它负责滚动入场（IntersectionObserver，只动 opacity 与 transform）与返回顶部。
- **只在 `<body>` 内替换内容**，照抄模板里已有的组件实例结构。
- 跑马灯内容需**复制两遍**放入 `.strip-track`（首尾相接实现无缝滚动）。
  ⚠ 用脚本批量替换「关键词」时注意：正则 `关键词一[\s\S]*?关键词六…` 会匹配两遍原文，
  若替换文本本身含「关键词」锚点或重复拼接，易产出 4 遍。稳妥做法：整段替换后校验关键词出现次数 == 2。
- 首屏 `<h1>` 中包裹 `<em>` 的部分会显示手绘下划线 SVG，只放最具冲突感的那一个词。
- 需要增删章节时，同步更新顶栏 `.navmenu` 的锚点与章节 `id`，导航最多 8 项。

## 设计基调（不需要改动，供理解约束）

- 字体：展示字 **Fraunces**（衬线）+ 正文 **Figtree**，中文回落到思源宋体 / 苹方 / 微软雅黑。禁止换成 Inter、Roboto、Arial 等默认字体。
- 配色：暖白纸底 `oklch(0.972 0.012 76)` + 单强调色 + 绿作为辅助语义色（适宜 / 有利）。
- 动效：首屏四段错峰入场（0 / 80 / 160 / 240ms），滚动渐显，跑马灯 32s 线性循环，全部在 `prefers-reduced-motion: reduce` 下关闭。
- 构成：非对称首屏（左文右旋转 1.2° 的卡片）、超大章节编号、破格的绝对定位花朵 SVG。
