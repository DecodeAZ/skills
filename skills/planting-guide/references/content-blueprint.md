# 指南内容蓝图：十章结构、写作规范与质检

## 一、固定十章结构

按目标植物、城市、位置取舍章节数量（8～10 节），但编号与顺序保持不变，
让不同城市、不同植物的指南保持一致的阅读路径。

| # | 章节 | 必须回答的问题 | 首选组件 |
|---|---|---|---|
| 01 | 环境真相 | 这个城市 + 这个位置，植物真正面对的矛盾是什么 | `.two` 左文右对比表 + `.tip` |
| 02 | 品种 / 植物选择 | 该选什么、不该选什么（附避坑清单） | `.three` 六张 `.vcard` + 选品铁律 `.tip` |
| 03 | 光照与位置 | 光够不够、要不要补光、怎么摆、怎么转盆 | `.ruler` 五步 + `.callout` |
| 04 | 浇水与湿度 | 多久浇一次、怎么判断干湿、控水促花怎么做 | `.two` 双栏，各带 `.ruler.plain` |
| 05 | 土壤与施肥 | 配什么土、各阶段用什么肥、什么频率 | 四列 `.compare` + 三戒 `.tip` |
| 06 | 修剪与整形 | 什么时候剪、剪哪里、怎么让株形更好 | `.three` 三张 `.vcard` + `.tip` |
| 07 | 越冬 / 度夏（极端季） | 极端温度下的生死线，以及四步防护 | 温度表 + 四步列表 + `.callout` |
| 08 | 病虫害 | 这个环境高发什么、怎么防、怎么治 | 四列 `.compare` + 第一道防线 `.tip` |
| 09 | 全年养护月历 | 各月分别做什么 | `.cal` 11 格（7–8 月合并）+ 口诀卡 |
| 10 | 常见问题速答 | 用户最可能问的 6 个问题 | 6 个 `<details>` |

**极端季章节的选择**：寒冷城市（7 区及以下）写「越冬」；炎热无霜地区（10–11 区）改写「度夏」；
两者都极端的地区（如长江流域：夏酷热 + 冬湿冷）保留两个 callout，章节标题写「越冬与度夏」。

## 二、写作规范

### 数字优先，形容词靠后
- 好：「年均日照 1000～1200 小时，朝北阳台直射光几乎为 0」
- 坏：「日照不太充足，光照条件一般」

### 每章必须有一个「反直觉结论」
读者是带问题来的，要给的是判断而不是说明书。例如：
- 「成都北阳台养三角梅，最大的杀手不是缺水，是浇太多」
- 「土壤越舒服，它越爱长叶子；一旦缺水受震撼，它就想赶紧开花」

### 城市/位置定制的三条硬要求
1. 首屏三个 `.stat` 数字，至少两个来自该城市/位置的真实数据（年均温、日照、极端低温、湿度、无霜期）。
2. 月历的每一格必须体现该城市的季节节奏（成都 3 月回暖换盆 ≠ 哈尔滨 3 月仍在室内越冬）。
3. 越冬/度夏章节的温度表，使用该城市的真实极值区间。

### 文案禁用清单（反 AI 味）
禁用：无缝赋能、一站式、全方位、打造、助力、赋能、解锁、新体验、极致、匠心、
让你的植物焕发生机、轻松成为养花达人、保姆级教程。
替代表达：直接给数字、给判断、给失败案例。

### 事实核查
- 城市气候数据以 `climate-zones.md` 为准，表中没有的城市必须联网核查后再写。
- 植物学名、耐寒区、毒性、药剂名称不确定的，联网核对；**有毒植物必须标注毒性**。
- 农药推荐写通用成分名（如吡虫啉、阿维菌素、多菌灵），不写具体商品名，并注明安全间隔期。
- 不确定处用区间与条件句（「约 3～5 天，视通风情况」），不要编造精确值。

## 三、首屏文案公式

- `KICKER`：`No.01 · 种植指南 / {城市}·{位置}`
- `H1`：主谓完整的一句话承诺，`<em>` 里放最具冲突感的那个词（城市名、朝向、或植物的核心难点）。
  例：让三角梅，在**成都的北阳台**也会开花
- `LEDE`：三句——① 植物的天性 ② 这个城市/位置与它冲突的地方 ③ 结论与解法概览。用 `<strong>` 标出 2～3 个关键词。
- `CORNER_*`：放「先认清的三个数字」这类认知前置，制造轻微的认知冲击。
- `STAT*`：三个数字 + 一句解释 + 一句后果。

## 四、交付前质检

- [ ] 城市与位置在首屏、月历、极端季章节中前后一致
- [ ] 三个 stat 数字至少两个有真实来源
- [ ] 月历格全部填写（7–8 月合并为一格，其余每月一格），最后一格是口诀卡
- [ ] 6 个 FAQ 全部填写，第一个默认展开
- [ ] 全部 `{{...}}` 占位符已被替换（全文搜索 `{{` 应为 0 命中）
- [ ] `data-theme` 已按植物类型选定（观花 bloom / 观叶 leaf / 果蔬香草 harvest）
- [ ] 无 AI 味文案，无空洞形容词
- [ ] 有毒植物已标注；农药写成分名
- [ ] 手机宽度（375px）下表格用 `.tbl-wrap` 横向滚动，不破版
