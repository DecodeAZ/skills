# 中国主要城市气候与耐寒区速查

生成指南时，先在这里定位目标城市的气候档案；表中没有的城市，按「就近气候区 + 联网核查」处理。
数值为常年气象统计的近似区间，用于确定养护基调，不要当作精确预报写进正文。

## 一、六个数决定一份指南

| 变量 | 为什么关键 |
|---|---|
| 年均温 | 判断整体生长季长短 |
| **极端低温 / 耐寒区** | 决定植物能否露天越冬，以及是否需要搬入室内 |
| **年日照时数** | 决定开花植物是否需要补光 |
| 无霜期 | 决定可露天种植的窗口 |
| 湿度特征 | 决定浇水频率与病害防控力度 |
| 雨季 / 旱季分布 | 决定排水策略与灌溉节奏 |

耐寒区采用 USDA 近似分区（数值越大越暖）：
3–4 区 极寒 · 5–6 区 寒冷 · 7 区 冷凉 · 8 区 温和 · 9 区 温暖 · 10–11 区 炎热无霜。

## 三、气候事件 → 养护动作映射

| 气候事件 | 高发地区 | 指南中必须出现的对策 |
|---|---|---|
| 梅雨（6–7 月连绵阴雨） | 江南、江淮 | 停肥、控水、搭雨棚、加强通风、预防黑斑/白粉 |
| 回南天（2–4 月返潮） | 华南 | 关窗、开除湿、暂停叶面喷水、预防根腐 |
| 台风 / 暴雨 | 华南、东南沿海 | 提前修剪疏枝、加固、搬入、雨后排水防涝 |
| 倒春寒（3 月断崖降温） | 长江流域及以北 | 春剪推迟到气温稳定后、出室推迟到清明后 |
| 干冷冬 + 暖气 | 华北、东北 | 增湿（托盘/加湿器）、远离暖气片、减少浇水频率 |
| 秋老虎（9–10 月高温） | 江南、华南 | 延后秋播、继续遮阴、防红蜘蛛 |
| 强紫外线 / 大温差 | 高原、西北 | 幼苗遮阴、早晚浇水、选耐紫外线品种 |
| 寡照（冬季连续阴天） | 四川盆地、贵州 | 补光灯、控水、降低肥料浓度 |

## 四、海外城市

目标城市在境外时，不要套用上表。按同一组变量联网检索：年均温、极端低温（USDA hardiness zone）、
年日照时数、无霜期、雨季分布，再套用本文「气候事件 → 养护动作」的映射逻辑。
