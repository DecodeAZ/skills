# 种植微环境：室内 vs 室外，朝向、玻璃与容器

「城市」只决定大气候，「位置」才决定植物每天真实感受到的光、温、湿、风。
同一座城市里，南向露台与北向客厅是两种完全不同的生境。本文件用于把用户给出的
位置描述（如「室外露台」「封闭阳台」「客厅北窗边」）翻译成可执行的养护参数。

## 一、光照强度标尺（勒克斯 lx）

| 场景 | 典型照度 | 适配植物 |
|---|---|---|
| 盛夏正午全日照 | 80000～100000 lx | 月季、三角梅、向日葵、多肉（需逐步炼苗） |
| 春秋晴天户外 | 30000～60000 lx | 绝大多数开花植物、果蔬 |
| 晴天户外树荫 / 遮阳网下 | 8000～20000 lx | 绣球、杜鹃、兰花、蕨类 |
| 封闭南向阳台（单层玻璃内侧） | 10000～25000 lx | 大部分开花植物可正常开花 |
| 开放南向阳台（无玻璃） | 20000～50000 lx | 全日照植物 |
| 室内南向窗边（0.3m 内） | 3000～8000 lx | 观叶植物、部分开花植物 |
| 室内东/西向窗边 | 1500～4000 lx | 耐半阴观叶、秋海棠、非洲堇 |
| 室内距窗 1.5m | 300～800 lx | 仅极耐阴植物（绿萝、虎皮兰、金钱树） |
| 室内北向房间 | 200～800 lx | 需补光灯才能养开花植物 |
| 全人工光（无窗） | 0 lx | 必须全光谱植物灯，每日 10～14h |

**距离衰减经验值**：距窗 0.5m 处约为窗边光强的 1/3，1.5m 处约 1/10，2.5m 以外基本等于无光。

## 二、玻璃与遮挡的衰减

| 介质 | 透过率 | 备注 |
|---|---|---|
| 单层透明玻璃 | 约 70～90% 可见光 | 几乎完全阻隔 UVB（对需紫外线的多肉上色不利） |
| 双层中空玻璃 | 约 60～80% | 冬季保温好，光照进一步打折 |
| Low-E 镀膜玻璃 | 约 40～60% | 新建住宅常见，室内实际光照远低于预期 |
| 磨砂玻璃 / 纱窗 | 约 30～50% | 会造成「明明有窗却养不好」的错觉 |
| 防盗网 + 遮阳棚 | 再衰减 30～60% | 需现场观察实际光斑 |
| 相邻楼栋遮挡（低楼层） | 视间距，可能衰减 80% | 楼间距小于楼高 1 倍时按弱光处理 |

**夏季增温**：封闭阳台在晴天正午可达 45～55℃，玻璃会形成温室效应；南向封闭阳台必须留通风口或遮阳。

## 三、室外位置档案

| 位置 | 光照 | 温度特征 | 主要风险 | 适配 |
|---|---|---|---|---|
| **露台 / 屋顶花园** | 全日照 6～10h，无遮挡 | 昼夜温差大，夏季地表温度极高 | 风大、蒸腾快、荷载与防水受限、夏季暴晒 | 月季、三角梅、铁线莲、果蔬、香草、松柏盆景 |
| **庭院地栽** | 视建筑与乔木遮挡，差异大 | 土壤缓冲，温度波动小 | 土壤板结/积水、地下害虫、根系竞争 | 木本花卉、乔木灌木、宿根花境 |
| **开放阳台 · 南向** | 直射 6～8h | 冬季冷、夏季烫，昼夜温差 10～15℃ | 高层风大、盆土速干、冬夜低温 | 绝大多数开花植物 |
| **开放阳台 · 东/东南向** | 上午直射 3～5h，下午散射 | 温和 | 夏季下午仍闷热 | 绣球、杜鹃、兰花、多数观叶 |
| **开放阳台 · 西/西南向** | 下午直射 4～6h，西晒强烈 | 夏季极端高温 | 日灼、失水过快 | 三角梅、太阳花、多肉、薰衣草 |
| **开放阳台 · 北向** | 几乎 0 直射，200～800 lx | 阴冷、冬季风大 | 光照不足、土干得慢、徒长 | 蕨类、竹芋、玉簪；开花植物需补光灯 |
| **封闭阳台（南向）** | 10000～25000 lx | 冬季高于室外 3～8℃，夏季可达 45℃+ | 通风差、夏季高温、病害 | 三角梅、茉莉、栀子、柑橘、多肉（冬季） |
| **封闭阳台（北向）** | 800～2500 lx | 冬季仍可能低于 10℃ | 光照严重不足 | 观叶植物 + 补光灯 |

## 四、室内位置档案

| 位置 | 光照 | 温度 / 湿度 | 主要风险 | 适配 |
|---|---|---|---|---|
| **南向窗边（0.5m 内）** | 3000～8000 lx | 冬季供暖 RH 20～35%；夏季空调房 RH 40～60% | 空调/暖气直吹、局部极干、玻璃夜间冷辐射 | 多肉、仙人掌、茉莉、天竺葵、龟背竹 |
| **东/西向窗边** | 1500～4000 lx | 温度较稳定 | 光照仍偏弱 | 秋海棠、竹芋、蕨类、网纹草 |
| **北向房间 / 办公室** | 200～800 lx | 稳定但光照几乎为零 | 徒长、不开花、烂根 | 绿萝、虎皮兰、金钱树、一叶兰；观花需补光 |
| **全人工光（无窗）** | 0 lx | 完全受控 | 电费、光谱与灯距 | 需全光谱灯每日 10～14h；适合叶菜、育苗 |
| **厨卫（高湿弱光）** | 500～2000 lx | RH 60～80%，油烟 | 油烟堵气孔、光照不足 | 绿萝、吊兰、铁线蕨（需通风） |
| **飘窗 / 阳光房** | 8000～30000 lx | 夏季极易超 40℃ | 夏季高温闷杀 | 需遮阳 + 排风，否则只能冬季使用 |

## 五、室内外共通的四个修正因子

1. **通风**：封闭空间风速趋近 0 → 蒸腾停滞、病害高发。对策：每日开窗 30 分钟以上，或用小风扇低速对流（不对植株直吹）。
2. **湿度**：供暖季室内 RH 常低于 30% → 叶尖焦枯、红蜘蛛爆发。对策：托盘垫石加水、加湿器、聚盆摆放。
3. **温度骤变**：暖气片旁、空调出风口、玻璃窗夜间冷辐射 → 局部温差可达 10℃ 以上。对策：植株与出风口、暖气片保持 1m 以上距离。
4. **容器**：陶盆透气但干得快，塑料盆保水，釉面瓷盆最不透气；地栽依赖土壤自身排水。屋顶/露台还需考虑风载与荷载。

## 六、把位置翻译成养护结论

收到位置描述后，按这个顺序形成结论并写进指南：

1. 判断日累计直射时长与照度区间 → 决定植物清单与是否需要补光灯。
2. 判断极端温度（夏峰值 / 冬谷值）→ 决定度夏与越冬章节的力度。
3. 判断通风与湿度 → 决定浇水频率与病害章节的重点。
4. 判断容器与空间约束 → 决定配土、换盆、修剪整形的具体建议。

若用户给出的位置描述模糊（例如只说「阳台」），必须追问朝向、是否封闭、楼层与遮挡情况——
这三项对结论的影响，与城市本身同等重要。
