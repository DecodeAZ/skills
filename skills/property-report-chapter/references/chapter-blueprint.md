# 章节内容蓝图：四类章节的结构与写作规范

按章节类型组织内容。每类章节的组件搭配、数据要求和写作重点如下。
组件用法直接照抄 `assets/chapter-template.html` 里已有的实例。

## 通用要求（四类章节都适用）

- **数字优先**：价格、面积、距离、容积率、评分——能用数字说清的，不用形容词。
- **每章有一个反直觉结论**：读者带问题而来，要的是判断而不是资料罗列。
- **图表 2–3 个**：至少一个反映"量"（柱状/条形），一个反映"结构"（环形/占比）或"对比"（雷达/分组）。
  图表数据必须与正文数字一致，不允许出现图上与文中对不上的情况。
- **指标卡 4 个**：放本章最关键、最能制造认知冲击的四个数字，每个附一句解释。
- **数据必须可溯源**：指标卡、图表、表格中的数字都要能追到 `data-sources.md` 里的来源平台。

## 禁用文案（反 AI 味）

禁用：尊享、臻品、匠心、赋能、一站式、全方位、势必、引爆、劲爆、绝版、抄底、
"价值洼地"、"下一个XX"、"买到就是赚到"、"错过再无"。

替代表达：给具体数字、给对比基准、给失败或风险案例。

## 一、户型产品分析（`floor-type`，主色蓝）

**要回答的问题**：主力户型是什么、各户型优劣如何、这个家庭该选哪个。

| 区块 | 内容 | 组件 |
|---|---|---|
| 指标卡 | 主力面积段、主力户型、得房率、户型种类数 | `.metrics` |
| 01 户型概览 | 产品定位、面积段分布、总户数与楼栋排布 | `.card` + 面积分布柱状图（`c1`） |
| 02 主力户型详解 | 逐个户型：面宽进深、房间数、朝向、优缺点 | `.tbl-wrap` 参数对比表 + `.compare` |
| 03 户型分布与选筹 | 面积段占比、楼层/楼栋差异、选筹顺序 | 环形图（`c2`）+ `.ruler` 分步 |
| 04 小结 | 哪个户型性价比最高、哪类家庭适合 | 评分条 `.score-row` + `.tip` |
| 05 常见问题 | 得房率怎么算、承重墙位置、改造可能性 | `details.faq` |

**户型示意图**：用 `.floorplan` + `.room` 的 CSS 网格绘制，不要插入外部图片链接。
例如三室两厅可按"3 列 × 2 行"排布：客厅横跨两列、主卧/次卧/卫/厨各占一格。

**数据要点**：建筑面积、套内面积、得房率、开间进深、朝向、层高、阳台形式。
得房率 = 套内面积 ÷ 建筑面积，注意区分"套内"与"使用"两种口径。

## 二、价格与竞品分析（`price`，主色红橙）

**要回答的问题**：这个价格贵不贵、和周边比有没有优势、未来会怎么走。

| 区块 | 内容 | 组件 |
|---|---|---|
| 指标卡 | 参考均价、总价区间、价格环比、与周边价差 | `.metrics` |
| 01 价格现状 | 备案价/成交价、价格构成（含装修、车位等） | `.card` + 价格走势图（`c1`） |
| 02 竞品横向对比 | 3–5 个竞品：均价、地段、产品、去化 | 对比表 + 雷达图（`c3`） |
| 03 价格优劣势 | 便宜在哪、贵在哪、什么在支撑价格 | `.compare`（优势/风险双栏） |
| 04 小结与展望 | 价格判断、观望还是入手、关注信号 | 评分条 + `.tip` + `.tip.risk` |
| 05 常见问题 | 特价房怎么来的、车位价格、贷款成本 | `details.faq` |

**价格口径必须写清**：备案价 / 网签均价 / 成交价 / 特价房是四个不同概念，混淆会误导。
标注为"参考均价"，并注明数据截止月份。

**竞品选择**：同行政区、同总价段、同产品类型；至少 3 个，最多 5 个，不要凑数。

## 三、交通与配套分析（`location`，主色青）

**要回答的问题**：住在这里通勤方便吗、孩子上学、看病、买菜方不方便。

| 区块 | 内容 | 组件 |
|---|---|---|
| 指标卡 | 最近地铁距离、通勤时长、学区数量、配套评分 | `.metrics` |
| 01 区位与交通 | 区位描述、地铁/公交/主干道、通勤时间 | `.card` + `.map-shell` 位置示意图 |
| 02 周边配套 | 教育/医疗/商业/公园四类配套清单与距离 | 分类卡片 + 配套距离图（`c1`） |
| 03 配套成熟度 | 已有 vs 规划中、兑现风险 | `.compare`（已兑现/待兑现双栏） |
| 04 小结 | 配套评分、主要短板、对哪类人最合适 | 评分条 + `.tip` |
| 05 常见问题 | 学区划分确定性、地铁开通时间、噪音 | `details.faq` |

**位置示意图**：用内联 SVG 按真实经纬度相对位置绘制，配合 `.map-legend` 的分类筛选按钮。
楼盘中心点用 `.pulse` 呼吸动画。**不要把外部地图截图或在线地图 iframe 嵌入文件**——
报告需离线可读，嵌入外部资源会在断网时失效。

**配套距离**：写"直线距离"或"实际路程"必须区分标注。地图 API 返回的是直线或路径距离，
不能混用，不能把导航距离写成"步行 5 分钟"而不说明测算方式。

## 四、总结与展望（`summary`，主色深紫）

**要回答的问题**：综合来看值不值得买、适合谁、有什么风险。

| 区块 | 内容 | 组件 |
|---|---|---|
| 指标卡 | 综合评分、价格分位、配套评分、风险等级 | `.metrics` |
| 01 综合评估 | 各维度评分与加权逻辑 | `.card` + 多维度评分条 + 雷达图（`c3`） |
| 02 核心结论 | 3–5 条明确结论（不骑墙） | `.ruler` |
| 03 发展展望 | 区域规划、兑现节奏、关键时间节点 | `.timeline` |
| 04 风险与适合人群 | 主要风险、什么家庭适合、什么家庭不适合 | `.tip.risk` + `.compare` |
| 05 常见问题 | 现在买还是等、租金回报、转手难度 | `details.faq` |

**评分维度建议**：区位交通、产品力、价格合理性、配套成熟度、品牌与交付。
每个维度给 1–10 分并写清评分依据，不给出处不明的分数。

**结论必须明确**：给出"更适合哪类需求"的判断，而不是"因人而异"这类无效结论。
同时必须附风险提示与免责声明。
