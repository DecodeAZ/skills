# 环境与依赖配置

本技能的自包含程度很高：生成章节所需的一切都在包内，只要运行环境满足要求即可。另有一个**可选依赖**（高德地图 MCP）用于「交通与配套分析」章节。已就绪的项不必重复配置。

## 1. python-runtime

骨架脚本 `scripts/new_chapter.py` 为纯标准库实现，但使用了联合类型语法，需要 **Python 3.10 或更高版本**；低于该版本会在解析阶段直接报 `SyntaxError`。

- 官方主页：https://www.python.org/
- 官方文档：https://docs.python.org/3/
- 安装步骤：
  1. 从上述官方渠道安装 Python 3.10 或更高版本；
  2. 确认 `python --version` 可执行；
  3. 本技能只用标准库，无需 `pip install`。
- 验证：`python --version`
- 安全：脚本无网络访问、无子进程，只读模板并写入用户指定的输出路径。
- 核验日期：2026-09-13；适用版本 `>=3.10`。

## 2. bundled-template

设计系统与骨架脚本都在包内，缺一不可。

- 官方主页：https://github.com/DecodeAZ/skills
- 官方文档：https://github.com/DecodeAZ/skills/tree/main/skills/property-report-chapter
- 需要存在的文件：`scripts/new_chapter.py`、`assets/chapter-template.html`
- 验证：`python scripts/new_chapter.py --out <输出路径> --chapter price --project 测试` 返回退出码 `0`
- 安全：只读模板并写入指定输出路径；目标文件已存在时会拒绝覆盖，需显式加 `--force`。
- 核验日期：2026-09-13；适用版本 `1.1.0`。

## 3. 可选依赖：高德地图 MCP

「交通与配套分析」章节可通过高德地图 MCP 获取精确坐标与周边 POI。**这是可选依赖**：未配置时核心流程照常运行，仅位置示意图改为基于公开信息的文字描述与手工坐标。仅做户型、价格、总结章节时不需要本依赖。

这一项需要账号与凭据，且高德方面未提供可核验的 MCP 服务入口，因此**不写入 `skill-dependencies.json`**；它的降级路径记录在该清单的 `map-location` 功能条目中。

### 触发条件

- 需要楼盘精确经纬度（用于按真实相对位置绘制位置示意图）
- 需要按类别批量检索周边 POI（学校、医院、公园、商业）及其距离

### 未配置时的降级

| 功能 | 降级方式 | 限制 |
|---|---|---|
| 楼盘坐标 | 从公开资料（楼盘地址）人工估算方位，或省略坐标 | 示意图为示意性质，比例不精确 |
| 周边 POI | 使用 WebSearch 检索公开配套信息（学校名称、商场名称等） | 无法给出精确距离，只能写区位关系 |
| 配套距离 | 用"直线距离估算"或"临近 XX 路"描述，不写具体公里数 | 不能标注为导航路程 |

降级结果**必须在报告中标注**：位置图为"示意"，距离为"估算"。核心章节不受影响，正常生成。

### 配置步骤（高德开放平台）

1. **注册账号**：访问 https://lbs.amap.com/ ，用手机号注册并完成开发者认证。
2. **创建应用**：控制台 → 应用管理 → 我的应用 → 创建新应用，填写应用名称与类型。
3. **添加 Key**：在应用下 → 添加 Key，服务平台选 **Web 服务**（不要选 Web 端 JS API）。
4. **记录 Key**：形如 `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`，**仅保存在本地配置或环境变量中，不要写进报告、Skill 文件或提交到仓库**。
5. **配置 MCP**：把高德 MCP 服务加入 WorkBuddy 的 MCP 配置（`~/.workbuddy/mcp.json`），由 WorkBuddy 的「连接器管理」界面完成信任启用。具体服务地址以高德官方 MCP 文档为准，不要凭记忆填写未知地址。
6. **验证**：配置完成后运行一次 `maps_geo` 查询一个已知地址，返回经纬度即成功。

### 权限与额度

- 高德 Web 服务 Key 的最小权限：地理编码、逆地理编码、周边搜索、路径规划。
- 个人开发者有每日调用额度限制，超限会返回错误码；额度与配额以高德控制台实时显示为准。
- 不要把 Key 共享给第三方，也不要放入前端代码或公开仓库。

### 凭据存储与轮换

- **存储**：环境变量（如 `AMAP_MAPS_API_KEY`）或本机 MCP 配置，绝不写入本 Skill 的任何文件、报告 HTML 或日志。
- **验证**：用一次最小只读请求确认 Key 可用。
- **轮换**：在高德控制台删除旧 Key、创建新 Key，更新本机配置后重新验证。
- **撤销**：控制台删除对应 Key 即可立即失效。

## 4. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `check_environment.py` 返回 `needs_setup` | 缺 Python 3.10+，或包内脚本/模板缺失 | 按第 1、2 节修复后重跑 |
| `SyntaxError: invalid syntax` | Python 低于 3.10 | 升级到 3.10+ |
| 退出码 `2` 且提示 `invalid choice` | `--chapter` 传了非法值 | 取 `floor-type` / `price` / `location` / `summary` |
| 退出码 `1` 且提示"目标已存在" | 输出文件已存在 | 换路径，或确认后加 `--force` 覆盖 |
| `INVALID_USER_KEY` | 高德 Key 错误或未生效 | 核对 Key 是否完整、是否已激活 |
| `DAILY_QUERY_OVER_LIMIT` | 高德当日额度用尽 | 等待次日重置，或降级为公开信息检索 |
| `USERKEY_PLAT_NOMATCH` | 高德 Key 平台类型不符 | 必须选「Web 服务」而非「Web 端 JS API」 |
| 返回空 POI 列表 | 搜索半径过小或类别词不匹配 | 扩大半径（学校 2km、医院 3km、公园 2km、商业 3km），或换用平台标准类别词 |
| MCP 工具不可见 | 未在连接器管理中信任启用 | 在 WorkBuddy 连接器管理页面完成信任后重启会话 |
