# 楼盘评估报告章节生成器

把「楼盘 × 章节类型」编译成一份可直接阅读、可分享的单文件 HTML 章节页面。
设计系统与组件固化在 `assets/chapter-template.html`，内容按楼盘与章节类型定制。

## 核心原则

1. **楼盘与章节类型是硬输入**。没有楼盘名，数据无从检索；没有章节类型，内容无从组织。缺失时必须先问。
2. **数字优先且可溯源**。价格、面积、距离、评分——能用数字说清的不用形容词，且每个数字都要能追到来源。
3. **样式不重写**。设计令牌与组件已固化在 `assets/chapter-template.html`，只替换内容层，不另造 CSS。
4. **自包含交付**。产出的 HTML 不依赖任何外部技能与外部图片；图表库缺省从 CDN 加载，离线或加载失败时自动降级为静态数据表，正文与数据表格始终完整可读。

## 工作流

### 第 1 步 — 收集参数（必做）

| 参数 | 说明 | 缺失时 |
|---|---|---|
| **楼盘名称** | 决定检索目标与全部数据 | **必须询问** |
| **章节类型** | 户型产品分析 / 价格与竞品分析 / 交通与配套分析 / 总结与展望 / 完整报告 | **必须询问** |
| 城市 / 区域 | 影响配套检索范围与竞品选择 | 可从楼盘名推断，推断不出时一并询问 |
| 输出目录 | 报告存放位置 | 默认用户工作区，不必追问 |

用户首句话已同时给出楼盘名与章节类型时，跳过此步直接进入检索。
一次问清缺失项，不要分多轮挤牙膏。

### 第 2 步 — 环境检查（只读）

先跑包内自检（**须在技能目录内运行**，`file` 检查按当前工作目录解析）：

```bash
cd "<本Skill目录>" && python scripts/check_environment.py
```

`ready` / `partial` 进入第 3 步；`needs_setup` 只展示缺失项的修复步骤（见 `references/setup-guide.md`）；`unavailable` 停止并说明原因。依赖与降级矩阵见 `skill-dependencies.json`。

其余依赖按需检查：

| 依赖 | 检查方式 | 未就绪时 |
|---|---|---|
| 高德地图 MCP（可选） | 尝试列出一个地图工具是否可见 | 仅影响位置示意图；按 `references/setup-guide.md` 降级，核心章节继续 |
| 网络检索 | WebSearch 是否可用 | 检索不可用时停止数据收集型章节，说明原因，不用记忆中的数据替代 |

配置齐全时跳过教程直接执行；缺失时只说明缺失项与影响，不做无关讲解。

### 第 3 步 — 数据收集

按 `references/data-sources.md` 检索与核验：

1. 用 WebSearch 检索公开信息，关键词组合见该文件的第六节（年份用当前年份）。
2. 关键数字（尤其价格）**至少两个来源交叉验证**；只有一个来源时标注出处并保留不确定性。
3. 明确每个数字的口径：价格是备案价/网签价/挂牌价，面积是建筑/套内，距离是直线/导航。
4. 检索不到的数据按该文件第五节处理，**不编造、不外推**。
5. 涉及位置与配套时，若高德地图 MCP 可用，先取楼盘经纬度，再按半径检索周边 POI。

### 第 4 步 — 生成章节骨架

```bash
python "<本Skill目录>/scripts/new_chapter.py" \
  --out "<工作目录>/<楼盘名><章节名>.html" \
  --chapter <floor-type|price|location|summary> \
  --project "<楼盘名>" --city "<城市>"
```

- 脚本自动注入主题色（按章节类型）、页面标题与章节标识，其余内容由第 5 步填写。
- 脚本打印待填占位符清单。
- **章节不需要的区块可整块删除**（如无地图章节删掉 `.map-shell` 相关块），删后确认 `data-chart` 与图表注册一一对应。

### 第 5 步 — 填写内容

按 `references/chapter-blueprint.md` 对应章节类型的结构填写，组件照抄模板已有实例：

| 内容类型 | 用哪个组件 |
|---|---|
| 关键指标概览 | 首屏 `.metrics` 四个 `.metric` |
| 量与分布 | `figure.chart` 的柱状 / 环形图（`c1`、`c2`） |
| 多维度对比 | 雷达图（`c3`）或 `.tbl-wrap` 对比表 |
| 优劣并列 | `.compare` 双栏（`.yes` / `.no`） |
| 分步解读 / 结论 | `.ruler` 大号序号列表 |
| 综合评分 | `.score-row` 评分条 |
| 时间节点 | `.timeline` |
| 一句话忠告 / 风险 | `.tip` / `.tip.warn` / `.tip.risk` |
| 位置示意 | `.map-shell` 内联 SVG + `.map-legend` 筛选按钮 |
| 户型示意 | `.floorplan` + `.room` 网格 |
| 疑问解答 | `details.faq`，第一个加 `open` |

图表数据在页面末尾 `__CHAPTER_CHARTS__` 段内定义，**颜色从 CSS 变量读取**，
`animation` 保持关闭，`resize` 监听已在模板中注册。

### 第 6 步 — 质检

- 全文搜索 `{{`，必须为 0 命中。
- 指标卡 4 个、图表 2–3 个；图上数字与正文、表格完全一致。
- 每个图表都有 `figcaption`（含来源与口径）与 `.chart-fallback` 静态数据表。
- 价格标"参考均价"并注明数据截止月份；页脚含数据说明、免责声明、生成时间。
- 未嵌入任何外部图片、iframe 或需联网的在线地图。
- 375px 宽度下表格用 `.tbl-wrap` 横向滚动，不破版。
- 无禁用词，每章有一个明确的反直觉结论。

### 第 7 步 — 交付

用 present_files 展示生成的 HTML，附 3～5 行说明：本章核心结论、最关键的 1～2 个数字、
以及数据口径与风险提示。

## 模板使用规则

`assets/chapter-template.html` 是设计的唯一来源，含完整令牌层、全部组件与图表脚本。生成章节时：

- **保留 `<style>` 块不动**。换主题色由脚本注入 `--accent` 系列变量，不要改其它 CSS 变量。
- **保留末尾三段 `<script>` 不动**（图表加载与降级、地图筛选、滚动渐显），只改
  `__CHAPTER_CHARTS__` 内的图表定义段。
- **只在 `<body>` 内替换内容**，照抄模板已有组件实例的结构。
- 删除区块时同步清理：`data-chart` 属性、`chart-<key>` 容器、`__CHAPTER_CHARTS__` 中对应注册。
- 首屏 `.crumb` 依次是楼盘 · 城市 · 报告类型，不要塞入其它信息。

## 设计基调（不需要改动，供理解约束）

- 字体：中文 **Noto Sans SC**，数字用等宽字体 `--num`；不引入其它字体依赖。
- 配色：冷白底 `#f8f9fb` + 单主题色（按章节类型）+ 语义色（success/warning/danger/purple）。
- 图表：ECharts SVG 渲染；缺省从 CDN 加载，加载失败则显示 `.chart-fallback` 静态数据表。包内**不附带** ECharts 库文件；若需图表离线渲染，把 `echarts.min.js` 放到产物同目录的 `assets/` 下，模板会优先加载它。
- 动效：仅滚动渐显与楼盘中心点呼吸动画，均在 `prefers-reduced-motion: reduce` 下关闭。
- 构成：渐变章节头部、悬浮于头部之上的指标卡、左侧强调线的图表说明。

## 注意事项

- 所有数据来自公开渠道，注明来源；不抓取需登录或付费的内容，不使用非公开信息。
- 价格一律标注"参考均价"，提醒以售楼处公示为准；必须含"仅供参考，不构成购房建议"免责声明。
- 不得写绝对化承诺（必涨、稳赚、保底收益等），不评价开发商信誉，不做学区承诺。
- 不含任何个人信息，不推荐中介、不放返佣链接、不做交易引导。
- 生成的 HTML 自包含：断网可读取全部正文与图表降级视图。
